# Type 1
If $f$ is continuous on $[t, b]$ for $a < t \leq b$, and $f$ is unbounded on $(a, b]$, we define
$$\int _{a}^b f = \lim_{ t \to a^+ }\int_{t}^b F $$
if this limit exists in which case the [[Integral]] is [[Convergent]]. if not, it is [[Divergent]]
